# Travel Booking System – Database Project

## Project Overview

This project was developed as a part of a Database Management Systems course. It simulates a full-scale travel booking platform where users can book flights, hotels, rental cars, and services using an integrated relational database.

## Features

- Database schema designed using ERD
- Includes flights, hotels, cars, and service bookings
- Covers secure payments and booking lifecycle
- Implements sample queries for reporting and analytics

## ER Diagram

![ER Diagram](./Travel_Booking_System_ERD.pdf)



## Business Rules

- A traveler can book multiple services
- One location can host multiple travel activities
- Users can leave ratings and reviews
- Payments are tracked for each booking

## Technologies Used

- MySQL
- SQL
- Draw.io / Visio (for ERD)
- Microsoft Word & PDF (for documentation)

## How to Use

1. Run the SQL script (`travel_booking.sql`) in MySQL Workbench or any DBMS.
2. Use `Sample_Queries.sql` to test data retrieval and reporting functionalities.
